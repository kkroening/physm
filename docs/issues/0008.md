# 0008 — Delete `testutils.ts`, which nothing imports and the lint config misnames

**Status:** Resolved
· **Kind:** Bug
· **Parent:** <a href="README.md" title="Issues">Issues</a>

> `physm-js/eslint.config.js` grants vitest globals to a list of test files that
> still names `src/testutils.js`. That file became `src/testutils.ts` in the
> TypeScript port, so the entry matches nothing.
>
> It is inert today, which is the reason to write it down rather than the reason
> not to: `testutils.ts` happens to use no vitest globals, so it needs nothing
> the block would grant. The moment something in there reaches for `expect` or
> `vi`, it gets a `no-undef` nobody will expect.

## Background

Spotted during review of [#18](https://github.com/kkroening/physm/pull/18),
which audited that same file for claims it no longer supported.

```js
files: ['**/*.test.{js,jsx,ts,tsx}', 'src/setupTests.js', 'src/testutils.js'],
```

The glob covers every test file by extension, so the two explicit entries are
for the helpers beside them. `src/setupTests.js` still exists;
`src/testutils.js` does not.

## Resolution

**Not by repointing the entry.** The "worth a glance" note above turned out to be
the whole issue: `testutils.ts` exports one function, `areClose`, and **nothing
imports it**. The file is dead.

Its own docstring records half of that — the tfjs helpers it used to hold went
when `Mat3` and `Vec3` became plain tuples with no lifetimes to manage. What it
does not say is that the survivor was superseded too: `mat3.equals` does the
same job and is used 26 times across the suite, while `areClose` is used nowhere.

So the file is deleted and the entry goes with it. `setupTests.js` stays named
explicitly, because it is genuinely not a test file — vite loads it through
`setupFiles` — and the glob covers everything else.

The original acceptance criterion is moot: there is no `testutils` to grant
globals to. The stale entry was a symptom of the file being unreachable rather
than a problem in itself, which is why the fix is smaller than the issue
proposed and removes more.
